# Support

For a reproducible bug, open an issue with the build ID, Windows version, affected component, exact steps, expected result, and actual result. For ideas, use the feature-request template.

Public issues are visible to everyone. Do not upload account identifiers, balances, positions, order histories, credentials, API keys, passwords, tokens, databases, licensing files, or unredacted screenshots.

For sensitive reports or security concerns, contact **support@decoglobal.us** privately. Do not post credentials by email either. Describe the issue first and arrange any further diagnostic sharing with support.

FastDOM also includes **Report a problem** in the app, where supported by your build. Review the report before choosing to send it.

This repository is for public documentation and feedback. Application source-code pull requests are not accepted because the application is proprietary and its source is not hosted here.
